# ASIF SUPER STORE POS

A modern, minimalist Point of Sale (POS) application built with C# and WPF.

## Features

- **Barcode-based Sale**: Quick item lookup using barcode scanners.
- **Modern UI**: Orange and grey themed, minimalist design for efficient operations.
- **Receipt Printing**: Integrated receipt generation with FBR Tax (GST) compliance.
- **Inventory Management**: Database-driven product and sales tracking.
- **Secure Login**: Counter-based authentication system.
- **MVVM Architecture**: Built using the Model-View-ViewModel pattern for better maintainability.

## Technologies Used

- **Language**: C#
- **Framework**: WPF (.NET Core/5+)
- **Database**: SQLite
- **Architecture**: MVVM
- **Reporting**: Custom Receipt Printing

## Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AliAhmed-git/POS-Counter-App.git
   ```
2. Open the solution in Visual Studio 2022 or later.
3. Restore NuGet packages.
4. Build and Run the project.

## Project Structure

- `Views`: XAML files for the user interface.
- `ViewModels`: Logic for UI interactions and data binding.
- `Models`: Data structures and database entities.
- `Services`: Business logic and database access layers.
